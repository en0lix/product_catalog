# Product Catalog

Каталог товаров с классами `Product` и `Category`.

## 📋 Описание

Проект содержит два класса:

- **Product** — описывает товар (название, описание, цена, количество)
- **Category** — описывает категорию товаров (название, описание, список товаров)
